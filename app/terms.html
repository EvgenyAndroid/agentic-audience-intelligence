No Fluff Advisory/Building Back to Your data

Your data · data terms

We don’t keep your data.

Your data is a demonstration, not a production service. A file you upload is used to decide and build audiences while you work, then deleted. These terms say exactly what happens to it.

What you agree to

  • You have the right to upload the file and to use it for this purpose.
  • You leave out direct identifiers (names, email addresses, phone numbers, postal addresses) and special-category data (health, religion, ethnicity, sexual orientation, political views). Use a pseudonymous key, such as an internal customer number, or synthetic data.
  • You treat every result as demonstration output: not advice, and not a basis for decisions about individual people.
  • Your invite key is for you. Don’t share it. It can be revoked at any time.

What happens to the file

  • Held for an hour at most. An upload and everything derived from it (the profile, decisions, models and scores) are deleted one hour after upload, when you press Delete this upload now, or when the server has been idle for 30 minutes, whichever comes first. The expiry time is shown on the upload step.
  • No copies. The file lives only on the disk of one server instance. There are no backups and no other storage, so a deleted file cannot be recovered.
  • Used only for your session. The file is profiled, routed and modeled for you, and for nothing else. It is not used to train or improve anything, not combined with other uploads, and not shared or sold.
  • Not sent anywhere. The server has no outbound internet access, and no row is sent to a language model.
  • Not logged. Row values are never logged. Cloudflare, which hosts the service, records request metadata such as time, path and status, as it does for any web request.
  • Kept apart. Each key has its own tenant and storage; one key cannot see another key’s uploads.

What stays with you

An audience you export is a file in your browser’s downloads. It is not kept on the server once the upload is deleted.

Questions

Ask through No Fluff Advisory. These terms describe how the demonstration works; they are not a data processing agreement. If you need one, ask before uploading.
